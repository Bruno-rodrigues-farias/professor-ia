# ⚙️ Configuração do projeto
- 1. Clone o projeto
- git clone URL_DO_REPOSITORIO
- 2. Entre na pasta
- cd english-mentor
- 3. Instale as dependências
- npm install
- 4. Crie o arquivo .env
- VITE_GEMINI_API_KEY=SUA_CHAVE_GEMINI
- 5. Rode o projeto
- npm run dev
